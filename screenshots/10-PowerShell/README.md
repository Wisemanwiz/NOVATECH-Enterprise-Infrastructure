# 💻 PowerShell Automation Screenshots

This folder contains screenshots demonstrating the PowerShell automation used to provision Active Directory users within the NOVATECH Enterprise Infrastructure lab.

## 📸 Screenshots

### 01 - User Provisioning Script
Displays the PowerShell script responsible for importing user information from a CSV file, creating Active Directory user accounts, assigning them to the appropriate Organizational Units, and adding them to department security groups.

---

### 02 - Users CSV File
Shows the CSV file containing employee information used as input for the automation script.

---

### 03 - Created Users
Demonstrates the successfully created user accounts within Active Directory Users and Computers after executing the automation script.

---

## 🎯 Objective

The purpose of this automation was to reduce manual user provisioning, standardize account creation, and demonstrate enterprise identity automation using PowerShell.
