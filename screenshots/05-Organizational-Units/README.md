# 🏢 Organizational Units (OU) Screenshots

This folder contains screenshots documenting the Organizational Unit (OU) design implemented within the NOVATECH Enterprise Infrastructure project.

## 📸 Screenshot Index

### 01 – OU Structure Overview
Displays the overall Organizational Unit hierarchy within the Active Directory domain.

### 02 – Departmental Organizational Units
Shows the departmental OU structure used to logically separate users by business function.

### 03 – Users Inside Department OU
Demonstrates user placement within a departmental Organizational Unit, supporting structured administration and policy management.

## 🎯 Purpose

These screenshots demonstrate the logical design of the Active Directory environment using Organizational Units to simplify administration, delegate management, and prepare the environment for future Group Policy deployment.
