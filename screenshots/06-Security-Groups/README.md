# 🔐 Security Groups Screenshots

This folder contains screenshots documenting the implementation of Active Directory Security Groups within the NOVATECH Enterprise Infrastructure project.

## 📸 Screenshot Index

### 01 – Security Groups Overview
Displays the Organizational Unit containing the Active Directory Security Groups created for each department.

### 02 – Group Properties
Shows the properties of a security group, including its name, scope, and type.

### 03 – Group Members
Displays the users assigned to a departmental security group, demonstrating successful group membership management.

## 🎯 Purpose

These screenshots provide visual evidence that security groups were successfully created and populated with users. This implementation follows enterprise best practices by organizing users into groups for simplified administration and future permission assignment using the AGDLP model.
