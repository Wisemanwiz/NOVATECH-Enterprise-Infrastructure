# 📸 File Services Screenshots

This folder contains screenshots demonstrating the implementation of enterprise SMB file sharing, departmental shared folders, and NTFS permission configuration.

## Screenshot Index

### 01 - File Server Overview
**File:** `01-file-server-overview.png`

Displays the Server Manager File and Storage Services console, showing the configured file server.

---

### 02 - Shared Folders
**File:** `02-shared-folders.png`

Shows all departmental SMB shares configured on the server.

Departments include:

- Executive
- Finance
- HR
- IT
- Marketing
- Sales

---

### 03 - Share Properties
**File:** `03-share-properties.png`

Displays the SMB share configuration for the Finance department including:

- Share Name
- Local Folder Path
- Share Protocol
- Server hosting the share

---

### 04 - NTFS Permissions
**File:** `04-ntfs-permissions.png`

Shows NTFS security permissions assigned to the Finance shared folder.

Permissions are assigned using Domain Local Security Groups in accordance with the AGDLP access control model.

---

## Purpose

These screenshots provide visual evidence that enterprise file sharing, SMB shares, and permission management were successfully implemented within the NOVATECH Enterprise Infrastructure project.
