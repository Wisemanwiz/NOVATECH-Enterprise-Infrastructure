# 📡 DHCP Screenshots

This folder contains screenshots documenting the deployment and configuration of the Dynamic Host Configuration Protocol (DHCP) service for the NOVATECH Enterprise Infrastructure project.

## 📸 Screenshot Index

### 01 – DHCP Manager Overview
Displays the DHCP Manager console with the configured IPv4 scope and server components.

### 02 – DHCP Scope
Shows the configured IPv4 scope, including the address pool used to lease IP addresses to client devices.

### 03 – Address Leases
Displays active DHCP leases, confirming that client devices successfully received IP addresses from the DHCP server.

### 04 – Scope Options
Shows the DHCP scope options configured for DNS server assignment and DNS domain name distribution.

## 🎯 Purpose

These screenshots provide visual evidence that DHCP was successfully deployed and configured to automatically assign IP addresses and network settings to domain-joined clients.
