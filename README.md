# 🏢 NOVATECH Enterprise Infrastructure

> A production-style Windows Server 2022 infrastructure built for a fictional enterprise (**NOVATECH**), demonstrating enterprise identity management, networking, centralized administration, file services, security, and PowerShell automation.

---

# 📖 Project Overview

The **NOVATECH Enterprise Infrastructure** project simulates the design and deployment of a modern Windows Server environment for a fictional organization.

The project focuses on implementing core Microsoft enterprise technologies while following industry best practices for planning, security, automation, and documentation.

Rather than building isolated services, every component was designed to work together as a complete enterprise infrastructure.

---

# 🎯 Project Objectives

- 🖥️ Deploy Windows Server 2022
- 👥 Configure Active Directory Domain Services (AD DS)
- 🌍 Implement DNS
- 📡 Configure DHCP
- 🏢 Design a scalable Organizational Unit (OU) structure
- 🔐 Implement Security Groups using the AGDLP model
- 📂 Configure NTFS Permissions and SMB File Shares
- ⚙️ Deploy Group Policy Objects (GPOs)
- 💻 Automate Active Directory user provisioning using PowerShell
- 📚 Produce professional technical documentation
